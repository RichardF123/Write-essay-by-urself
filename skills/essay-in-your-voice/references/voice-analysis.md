# Personal voice analysis

## Establish a usable sample set

Generate a private source manifest from the uploaded files: sample ID, local locator, date if known, language, genre, task constraints, author-written span, editing history if supplied, and relevance to the target. This inventory is agent work, not a prerequisite the user must fill out. A filename with multiple names is not evidence against the user's authorship statement. In mixed notebooks, isolate narrative analysis from prompts, library documentation, code, outputs and formulas.

Prefer several independent pieces and sustained reasoning passages. Three to five samples is a practical starting suggestion, not a validity threshold. Avoid duplicate drafts overweighting one passage. If possible, reserve one original passage as a holdout to test the profile instead of using it to generate rules.

## What to inspect

| Dimension | Look for | Avoid concluding |
| --- | --- | --- |
| Vocabulary | ordinary verbs, technical nouns, recurring explanatory phrases, precision, repetition | “No advanced vocabulary” because a few terms are unfamiliar |
| Syntax | clause function, sentence-length variation, openers, pronouns, relative clauses, punctuation | “Always use short sentences” from notes alone |
| Reasoning | what is known → possible explanation → what to check → limited judgment; or other actual sequences | Every author must follow this sequence |
| Comparison | shared basis, changed condition, internal counterexample, consequence for an interpretation | Balanced A/while/B sentences always match the author |
| Evidence and stance | observation vs inference, source attribution, disagreement, uncertainty and choice | Add “I think” to make analysis personal |
| Paragraph movement | how each sentence changes the next question; how paragraphs open and end | Every paragraph needs identical claim/evidence/summary shape |
| Genre dependence | notes vs reports, explanation vs discussion, academic vs informal | Copy casual syntax into a formal assignment |

The reasoning sequence above is a candidate from the originating case, not a fixed profile for future users. Look for evidence against it.

Each retained habit needs: an actionable rule, genuine sample locator, short quote or precise paraphrase, contexts of recurrence, counterexample/limitation, confidence, and how it transfers to this essay. A habit recurring across independent relevant samples supports more confidence than one forced by an assignment prompt. An absence in a small corpus supports only “not observed,” not “never use.”

## Metrics as checks, not identity scores

If measured, document selected spans, tokenization, exclusions and segmentation. Report distributions or ranges by genre, not invented exact whole-document averages. Abbreviations, citations, mathematical notation and OCR errors affect sentence metrics. Counts of `which`, `while`, or sentence length can disprove a simplistic style claim; they do not provide a word quota or an authorship probability.

Keep necessary grammatical improvements. Do not reproduce an accidental comma splice to sound authentic. Differentiate simplification from loss of reasoning: splitting a sentence should not erase which condition supports which conclusion.

## Validate the profile

Compare the rules against the holdout if available. Note misses, not just matches. Before a large revision, use a small in-scope paragraph as calibration where useful; do not make user approval a mandatory gate if they already requested the full edit. Preserve facts and rubric functions in this trial.

Update the profile when the user says a passage does not sound like them. Treat that as direct preference evidence; recheck the originals to understand the cause. Do not feed the latest assisted revision back as proof of an original habit. A profile remains provisional until the evidence and user feedback support it.

## Keep a compact calibration card

Retain only the few choices that materially guide this revision: preferred everyday verbs, typical clause relationships, concrete ways of citing visible evidence, transitions with a real function, pronoun use and genre boundaries. Each choice needs a source locator. Record user corrections alongside the affected rule so later turns do not revive a rejected house style.

Use a meaning-preserving micro-comparison on the same supplied claim to test an editing choice. Evaluate the version by its fit to originals and its local context, not whether it has more first person or fewer long words. If a held-out original contradicts a rule, narrow the rule instead of editing the evidence away. Do not copy the originating user's vocabulary, subject or reasoning into another user's profile.

Before delivery, compare the edited passages to these anchors. Check for vocabulary inflation, overly uniform short sentences, unnecessary synonym substitution, method declarations repeated in place of results, and accidental changes to who is compared with whom. These are review questions, not universal bans; preserve the writer's genuine formal language and necessary technical terms.
